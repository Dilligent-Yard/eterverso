Recuperação de dados locais

Esta página lê o armazenamento deste navegador sem iniciar a aplicação antiga. Os arquivos são gerados aqui e baixados pelo navegador; nada é enviado ao servidor.

Guarde a cópia bruta em local privado. Ela pode conter dados pessoais ou credenciais antigas. A conversão abaixo cria um arquivo separado com conteúdo e associações mínimas de autoria; ela não altera nem substitui a cópia bruta. Revise também o texto do conteúdo para encontrar segredos que alguém possa ter escrito dentro de uma postagem.

1. Snapshot bruto, sem alterações

Verificando o armazenamento local…

O JSON bruto é baixado exatamente como a string foi armazenada. O sidecar informa a origem, o rótulo e o SHA-256 do arquivo bruto.

2. Converter uma cópia em conteúdo

Use a cópia deste navegador, cole um snapshot sintético ou escolha um arquivo JSON exportado. O conversor mantém IDs antigos e relações de autoria como rótulos; remove contas, credenciais, permissões, sessões, contadores e outros campos fora da lista de conteúdo. HTML legado é preservado como dado e não é executado nem sanitizado nesta etapa.

O campo é uma cópia editável. Alterá-lo não grava no armazenamento local.
